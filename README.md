# Cafe Made In 2020

A multi-page website for Cafe Made In 2020, a cozy cafe in Ambernath. Features a vibrant design with skeleton loading animations, menu categories, Google reviews, and responsive layout.

## Live Site

[madein2020.vercel.app](https://madein2020.vercel.app)

## Tech Stack

- **HTML** with semantic structure
- **Tailwind CSS** (CDN) for styling
- **Vanilla JavaScript** for interactivity
- **Google Fonts** (Playfair Display, DM Sans)
- **Material Symbols** for icons

## Features

- Hero section with fan favourites showcase
- Vibe gallery with image grid
- Google reviews integration
- Menu page with category tabs and smooth scrolling
- About page with cafe story
- Contact page with location and hours
- Skeleton loading animations
- Responsive design with mobile hamburger menu

## Pages

- `index.html` — Home with hero, fan favourites, gallery, and reviews
- `menu.html` — Full menu with category tabs
- `about.html` — Cafe story and values
- `contact.html` — Location, hours, and contact info

## Deployment

Deployed on Vercel. Push to `main` to trigger automatic deployments.
